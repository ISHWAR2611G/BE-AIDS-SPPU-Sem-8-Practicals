Distributed Hotel Booking System using Java RMI

Steps to Run (Linux):

1. Compile:
   javac *.java

2. Run Server:
   java HotelServer

3. Open new terminal and run client:
   java HotelClient

4. Use options:
   1 - Book Room
   2 - Cancel Booking
   3 - Exit

Note:
- Always start server first
- Port used: 1099
